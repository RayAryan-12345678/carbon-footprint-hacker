// The pipeline

# 1. Browser sends your 12 inputs
POST /api/predict { transport_mode, km_per_month, flights_per_year, ... }

# 2. Flask encodes categories to numbers using encoders.pkl
'car_petrol' → 0, 'mixed' → 2, 'omnivore' → 3 ...

# 3. GradientBoostingRegressor predicts exact CO2
regressor.predict(X) → 380.4 kg/month

# 4. Ensemble classifies your tier
final = NaiveBayes × 0.35 + GBClassifier × 0.65 → tier + confidence

# 5. Score, breakdown, suggestions and trend are computed and returned as JSON
